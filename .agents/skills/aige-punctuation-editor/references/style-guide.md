## 1. 判断顺序

依次回答：

1. 这几行共同表达一个思想，还是分别表达独立观点？
2. 同一思想内部有几层关系？
3. 每一项是快速列举项、短分句、复杂分句，还是完整观点？
4. 作者是否在抒情或结尾处有意制造强停顿？
5. 修改是否具有充分把握？

先完成以上判断，再选择符号。

## 2. 人工确认的优先规则

1. 遇排比句时使用逗号或分号：简短、紧密、同层的排比句使用逗号；较长、内部已有逗号或层级较重的排比句使用分号。共享主语的短动词结构，只要补全主语后分别构成完整判断，也视为排比句。完整排比句、独立动作句和判断句不使用顿号。
2. 遇名词或名词性短语列举时使用顿号。多个短项共享同一谓语、实际列举同类对象时，也可按名词性列举处理。
3. 后句以“而、也”承接前句时，前句使用逗号，不用句号截断；其他承接词结合完整语意判断。
4. 引语后没有同一语意继续时，不在后引号外额外添加句号或逗号；外层句子仍在继续时，按外层句法在后引号外补充连接标点。

这三条是经人工确认的爱格编辑实践。与旧范例或一般化经验冲突时，优先执行本节。

## 3. 五类核心标点

### 顿号：名词或名词性短语列举

列举项的核心是名词或名词性短语时使用顿号：

```text
没有官服、
没有仪仗、
没有显赫的身份，
却比任何时候都更像他自己。
```

```text
是 Ithaca、
是 Penelope、
是孩子、
是家。
```

即使各项前面重复“没有”“是”等相同提示成分，也要判断真正被列举的核心是否为名词或名词性短语。

多个短项共享同一谓语、实际列举同类对象时，可使用顿号：

```text
必须进入时间、进入关系、进入我们的日常选择。
```

### 逗号：同一语意链中的紧密分句

适用于紧密并列、转折承接、前句未完成、简短平行说明，以及结构较短、关系紧密、层级相同的排比句：

```text
AI越来越聪明，信息越来越丰沛。
世界越来越快，竞争也越来越激烈。
```

```text
佛家或称之为自在，
儒家或称之为从容，
道家或名之为顺其自然。
```

```text
Home从来不只是一个地方，
它也是一种生命状态。
```

不要因为分行而自动使用句号。

后句以“而、也”承接前句时，前句使用逗号，不用句号截断。

### 分号：同一思想中的较大并列层次

适用于内部已有逗号、结构较长、语意分量较重或成组对照的排比句：

```text
年轻时，他希望改变世界；
后来，他不得不面对世界无法如愿的部分；
再后来，他开始更深地认识自己、安顿自己，也修炼自己；
到最后，他已经不再需要世界来证明自己。
```

```text
不是不再受伤，
而是受过伤以后，依然能够爱；
不是不再遭遇风雨，
而是在风雨之后，生命反而变得更加辽阔。
```

不要仅因有三句或内容相关就使用分号。简短、平层、共同完成一句话的排比句通常用逗号。

共享主语的短动词结构，只要补全主语后能分别形成完整判断，也可构成分号排比：

```text
可以爱；
可以逃；
可以嬉笑怒骂；
可以继续做那个没有被真正束缚住的自己。
```

### 句号：完整思想的收束或有意的节奏落点

一组排除、解释或列举完成后使用句号；下一段即使相关，也可能是新的定义：

```text
平常心，并不是凡事无所谓，不是压抑情绪，更不是用一句“随遇而安”，为逃避现实寻找借口。

真正的平常心，是……
```

抒情结尾允许用句号制造独立落点，但后句以“而、也”承接前句时，仍使用逗号连接：

```text
生命便不必等待未来的某一天，
而会在每一个当下，自然舒展、自然丰盛、自然绽放。
```

内容相关不等于必须共用一句。

### 冒号：提示后文解释或列举

前文明确提出一个待展开的“事情、问题、回答、原因或内容”，后文紧接解释或列举时使用：

```text
这些年，我一直在努力创造一些比自己更大的事情：
```

若后文只是新的推进而非解释或列举，不使用冒号。

冒号只决定提示关系，不直接决定分行。冒号后的移动端分行由公众号推文排版技能根据内容长度和视觉效果处理。

## 4. 引语内外标点

- 先判断引语本身是否结束，再判断引语所在的外层句子是否结束。
- 引语后没有同一语意继续时，不在后引号外额外添加句号或逗号。
- 引语后仍有同一外层句法中的内容紧跟时，在后引号外使用逗号等标点承接。
- 不因引语内部已有问号或句号，就忽略外层句子的连接关系。

独立呈现、后文不承接：

```text
“逝者如斯不舍昼夜”
```

外层语意继续：

```text
不是：“今天完成了多少事情？”，
而是今天的生命是否流向了真正重要的地方。
```

## 5. 语意结构范例

### `不是……而是……`

一组内部通常用逗号；多组并列时，组间用分号：

```text
真正的修养，并不是少做事，
而是做事时，不被事情吞没；
不是不要结果，
而是不把自己全部交给结果；
不是放弃改变世界，
而是在改变世界的同时，不忘修炼自己。
```

### 两层关系

第一句表达完整判断时使用句号收束；后两行共同表达第二个判断，并以逗号连接“也……而……”的承接关系：

```text
真正的平静，不是世界没有风雨。
真正的自由，也不是世界任我所欲，
而是在风雨之中，依然能够安住本心。
```

### 连续动作与快速列举

若多个独立行动构成排比或推进，用逗号或分号；完整排比句、独立动作句和判断句不使用顿号。若列举的是名词或名词性短语，用顿号。先判断列举内容的语法性质和语意层级，不以换行形式决定标点。

## 6. 风格边界

- 保留散文式呼吸，但不以“有节奏”为由掩盖明显层级。
- 不主动给“自在”“从容”“顺其自然”等普通概念加引号。
- 不将国家标准当作唯一答案；标准用于排除明显错误，人工确认的公司实践决定风格边界。
- 不追求全篇机械一致。同一符号在叙事、论述和抒情结尾中的功能可能不同。
- 后句以“而、也”承接前句时，使用逗号衔接，不以抒情节奏为由改用句号。
- 不从手机端视觉效果反推标点。分行、留白和标题拆分由独立的公众号推文排版技能处理。
- 两种标法都合理时保留原文。
- 新的人工定稿优先级高于本指南；发现稳定新模式后更新指南。

## 7. 校订检查表

- 是否先读完上下文再修改？
- 是否把换行误当作句末？
- 是否识别快速列举与完整分句的区别？
- 是否仅在名词或名词性短语列举中使用顿号？
- 是否在排比句中按层级正确选择逗号或分号？
- 是否统一以完整的排比句作为逗号或分号的判断对象？
- 共享主语的短动词结构，补全主语后是否能分别形成完整判断？
- 后句以“而、也”承接前句时，是否用逗号连接而没有误用句号？
- 引语结束后，是否继续检查了外层句子有没有结束？
- 是否只判断冒号的提示关系，没有把分行当作冒号的硬规则？
- 是否在复杂并列层次之间使用分号？
- 是否在完整思想结束处使用句号？
- 是否误把“内容相关”当作“必须连接”？
- 是否保留抒情段落的节奏性句号？
- 是否未经必要给普通概念增加引号？
- 是否仅修改标点，没有改动文字、分行、段落、语序和风格？
- DOCX 中是否只将修改标点及其前一字统一标蓝，且没有扩大标记范围？
- 是否对低把握修改保持克制？
