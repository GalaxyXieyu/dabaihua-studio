- 依据：“那个”直接修饰后文，不使用冒号割裂。

## 44 · 第十节·归途

- 原文：即使身份、成败、环境都发生变化：**我还能不能安住自己？**
- 修改：即使身份、成败、环境都发生变化，**我还能不能安住自己？**
- 依据：条件分句与主句之间使用逗号，不使用第二个冒号。

## 45 · 第十节·使命问题

- 原文：当我开始知道自己真正爱什么：**我愿意把这份爱带向哪里？**
- 修改：当我开始知道自己真正爱什么，**我愿意把这份爱带向哪里？**
- 依据：条件分句与主句之间使用逗号。

## 46 · 第十节·立志问题

- 原文：既然已经知道什么值得：**我愿意把有限的力量真正交给什么？**
- 修改：既然已经知道什么值得，**我愿意把有限的力量真正交给什么？**
- 依据：条件分句与主句之间使用逗号。

## 47 · 第十节·有限

- 原文：时间有限。 / 生命有限。 / 注意力有限。 / 关系有限。 / 能够真正全心投入的事情，也非常有限。
- 修改：时间有限， / 生命有限， / 注意力有限， / 关系有限， / 能够真正全心投入的事情，也非常有限。
- 依据：短而紧密的同层排比使用逗号。

## 48 · 第十节·五句提醒

- 原文：**安心，使我们不失去自己。** / **爱，使我们在乎。** / **使命，使爱有方向。** / **立志，使力量有方向。** / **知行合一，使方向成为人生。**
- 修改：**安心，使我们不失去自己；** / **爱，使我们在乎；** / **使命，使爱有方向；** / **立志，使力量有方向；** / **知行合一，使方向成为人生。**
- 依据：五个完整定义构成同层排比，使用分号。

## 49 · 第十节·使命成为生命

- 原文：使命也不再是生命之外的一项任务。 / 而成为生命本身展开的方向。
- 修改：使命也不再是生命之外的一项任务， / 而成为生命本身展开的方向。
- 依据：后句以“而”承接前句，使用逗号。

## 50 · 第十节·立志收束

- 原文：不是突然成为一个更宏大的人。 / 而是越来越诚实地成为自己。 / 越来越清楚自己真正爱什么。 / 越来越愿意放下那些不属于自己的东西。 / 再把有限的时间、注意力、能力与生命， / 一点一点交给那些真正值得的事。
- 修改：不是突然成为一个更宏大的人， / 而是越来越诚实地成为自己， / 越来越清楚自己真正爱什么， / 越来越愿意放下那些不属于自己的东西， / 再把有限的时间、注意力、能力与生命， / 一点一点交给那些真正值得的事。
- 依据：“不是……而是……”及后续连续推进共同完成一个收束句，使用逗号。

- 原文：**爱，使我们在乎。** / **使命，使爱有方向。** / **立志，使力量有方向。** / **知行合一，使方向成为人生。**
