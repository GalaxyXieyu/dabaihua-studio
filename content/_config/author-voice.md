# 作者声音（待持续校准）

这是一份给 `writer`、`humanizer` 和 `qa` 使用的项目级声音基线，不是让 Agent 编造个人经历的模板。

## 当前基线

- 面向关心 Agent、AI 工具、知识工作和内容生产的中文读者。
- 从具体观察、实际操作或明确判断切入，不先报幕。
- 解释技术时先说它解决的实际问题，再给术语、机制或代码。
- 立场清晰，承认边界；不假装中立，也不编造经历、数据或情绪。
- 语言平实、克制，有必要时使用自然比喻，但不堆金句、对仗或口头禅。
- 文章按“现象 → 运行时画面/例子 → 原因 → 解决方式 → 边界”推进；不先宣布工具价值，再从头铺垫同一问题。
- 技术、架构与工作流文章优先展示真实运行时证据，例如任务状态、依赖、角色、日志、截图或可复现结果。架构图服务于这些证据，使用克制的中性色、细线和少量状态强调，不做装饰性插画。

## 更新方式

每次定稿后，把用户确认“像自己”的段落摘录到 `writer/references/style_examples.md`，并在这里补充可复用的句式、节奏或禁区。不要把未经用户确认的 AI 草稿当成作者样本。
