## 选题建议

### 选题 1：「阿里云说 Agent 要组队，我在 Mac mini 上已经组了一支」

- **类型**: 蹭热点 + 实战差异化
- **为什么现在写**: AgentTeams/AgentLoop 本周刷屏，企业级"多智能体协作"叙事正热，但全是产品宣传稿，没有个人视角的落地样本
- **核心角度**: 企业还在讨论 Agent 怎么组队，我一个独立开发者已经在 Mac mini 上跑了一支 24h 的微型 Agent 团队——选题 Agent（每日订阅分析）、采集 Agent（公众号下载）、运维 Agent（看门狗/登录守护）。企业级方案解决的是"规模化"，个人方案解决的是"活下去"，架构思路完全不同
- **你的优势**: 这就是你的差异化定位——别人讲概念，你晒运行日志。有真实的进程守护、失败重试、登录态续期踩坑
- **参考素材**: 阿里云云原生 AgentTeams/AgentLoop 系列文、你的 wechat-collector + topics CLI + 每日自动化架构
- **平台**: 公众号 + 掘金
- **预估流量**: ★★★★☆（热点叙事 + 反常识对照）

### 选题 2：「新模型一周三发，我的自动化系统怎么不被拖垮」

- **类型**: 热点评论 + 架构实战
- **为什么现在写**: LongCat-2.0 开源 + GPT 5.6 周四全量 + GPT-Live 发布，模型更新密集到开发者开始焦虑"又要改代码了"
- **核心角度**: 模型会越来越快过时，但你的自动化系统不能每次跟着重写。讲讲怎么在 pipeline 里做模型抽象层——切换模型只改一行配置，prompt 与模型解耦，失败自动降级到备用模型
- **你的优势**: 这是"AI Agent 落地最痛的 5 个问题"的自然延伸，且蹭的是三个热点的交集而不是单一热点，生命周期更长
- **参考素材**: 赛博禅心 GPT 5.6/GPT-Live/LongCat 三条资讯、你自己的 pipeline 模型切换实践
- **平台**: 公众号 + 即刻（短评版）
- **预估流量**: ★★★★☆（三热点交集 + 实用焦虑共鸣）

### 选题 3：「Claude Code Skills 用了 30 天，我的管理心法」

- **类型**: 高优先级池 + 蹭 Skill 治理热点
- **为什么现在写**: 阿里云刚发"Skill 治理最佳实践"，企业视角的 Skill 管理开始有讨论度，但个人开发者的 Skills 实战内容几乎空白。这篇在你高优先级池里躺了一周，现在有了热点引子
- **核心角度**: 企业讲"治理"，个人讲"心法"——30 天攒了 N 个 Skill 后，哪些真的每天用，哪些写完就吃灰；Skill 之间怎么调用、怎么版本管理、怎么避免 prompt 膨胀
- **你的优势**: 你有 pm skill 改造、项目注册表、语义路由的真实改造记录，这是最硬核的素材
- **参考素材**: 阿里云云原生"一份可信来源，终结 Skill 管理混乱"、你的 pm skill 改造记录
- **平台**: 公众号长文 + 掘金
- **预估流量**: ★★★☆☆（垂类深度文，慢热但精准吸粉）
