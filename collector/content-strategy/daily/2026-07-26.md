## 选题建议

### 选题 1：「Opus 5 出来后，我把自动化流程重新跑了一遍」

- **类型**: 蹭热点 + 实战测评
- **为什么现在写**: Opus 5 刚发布 1 天，正是流量高峰期
- **核心角度**: 不是 benchmark 跑分，而是"我用它跑了我真实的自动化任务（公众号采集+文章下载），速度/质量/成本对比"
- **你的优势**: 你有真实的自动化 pipeline 可以测试，别人只有 demo
- **参考素材**: 赛博禅心"Opus5 官方 Prompt 指南"、数字生命卡兹克"Claude Opus 5 深夜发布"
- **平台**: 公众号 + 掘金
- **预估流量**: ★★★★☆（新模型 + 真实场景）

### 选题 2：「我用 Claude Code 给自己造了一个 24 小时内容引擎」

- **类型**: 品牌建立 + 实战故事
- **为什么现在写**: 这是你个人品牌的"创始故事"，任何时候写都不晚，但越早越好
- **核心角度**: 从"信息焦虑"到"自动采集"到"智能选题"，完整的工具链搭建过程。重点讲踩坑（登录态过期、队列卡死、Keychain 沙箱）和解决思路
- **你的优势**: 这个故事只属于你。有架构图、有故障、有修复、有数据
- **参考素材**: 清流阅读整个项目本身就是素材
- **平台**: 公众号长文（首篇品牌文）
- **预估流量**: ★★★☆☆（故事型，慢热但建立认知）

### 选题 3：「美团 LongCat 开源了，但 AI Agent 落地的坑不在模型」

- **类型**: 热点评论 + 观点输出
- **为什么现在写**: LongCat 今天刚开源，大家都在讨论模型本身，你可以切一个不同角度
- **核心角度**: "模型越来越强，但 AI Agent 落地最难的不是模型——是登录态管理、是错误恢复、是进程守护。我用 30 天实战经验告诉你真正的坑在哪"
- **你的优势**: 苍何写过"AI 出海最大的坑不是模型"，你可以写"AI Agent 落地最大的坑也不是模型"
- **参考素材**: 苍何"AI出海最大的坑，不是模型"、阿里云云原生 AgentLoop 系列
- **平台**: 即刻（短平快）+ 公众号（深度版）
- **预估流量**: ★★★★☆（蹭热点 + 反常识观点）

## 我的推荐优先级

**先写选题 2**（品牌故事），因为它是你所有后续内容的地基。读者需要先知道"你是谁"才会关心"你怎么看"。

然后选题 1 和 3 轮流蹭热点，保持曝光。
